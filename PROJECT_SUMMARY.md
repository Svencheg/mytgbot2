## 🚀 Быстрый старт для разработчика

### Шаг 1: Настроить secrets.txt
```bash
nano secrets.txt
```

Заполнить:
- TELEGRAM_BOT_TOKEN (получить от @BotFather)
- GEMINI_API_KEY (получить на https://aistudio.google.com)
- AUTHORIZED_USER_IDS (свой Telegram ID от @userinfobot)

### Шаг 2: Проверить конфигурацию
```bash
./check-config.sh
```

### Шаг 3: Начать реализацию
Следовать `DEVELOPMENT_GUIDE.md` по порядку:
1. ConfigurationLoader
2. SQLiteStorage
3. PluginManager
4. KlipperPlugin (базовые функции)
5. GeminiProvider
6. TelegramBotHandler
7. Собрать всё вместе

### Шаг 4: Запуск
```bash
./start.sh
```

## 🎨 Архитектурные решения

### 1. Плагиновая архитектура
Любую функциональность можно добавить через плагин, не трогая ядро.

### 2. Провайдеры AI
Легко сменить AI (Gemini → OpenAI → custom) через интерфейс.

### 3. Разделение ответственности
Каждый слой отвечает за своё:
- Core - бизнес-логика
- AI - обработка запросов
- Bot - работа с Telegram
- Storage - данные
- Plugins - интеграции

### 4. Асинхронность
Все IO операции асинхронные (async/await).

### 5. Расширяемость
Легко добавить:
- Новые плагины (умный дом, погода, TTS)
- Новые AI провайдеры
- Новые источники данных (не только SQLite)
